# daikibo-telemetry-task
Converts two different IIoT telemetry data formats into a unified JSON structure with normalized timestamps.

This project processes telemetry data from industrial IoT devices provided in two different formats and converts them into a single unified structure.

It standardizes fields such as device information, location, and operational data, and converts timestamps into milliseconds since epoch.

The solution ensures consistency across data streams and passes all provided unit tests.
